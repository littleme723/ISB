PNU Pedagogy

What is Vibe Coding?

Instead of manually writing boilerplates line-by-line, students at Pusan National University utilize generative AI prompts to express high-level architectural intentions ("vibes"), then iterate and refine real data pipelines rapidly.

View Sample Prompts
1

Intent Prompting

Describe physical domain concepts (e.g. thermal matrices, weather indices) in plain text.

2

Rapid Synthesis

Generate fully responsive Canvas, Chart.js, and API structures instantly inside one file.

3

Interactive Refinement

Fine-tune edge cases, thresholds, dark mode, and UI polish with high precision.

Lecture Prompts Used in Vibe Coding

PROMPT #1 — Thermal Analysis 1 
"Act as a computer vision & sensor data engineer. Build a single-file web app in HTML5 Canvas that accepts a 20x20 matrix of thermal temperature readings (20°C to 80°C). Convert this matrix into an interpolated smooth heatmap image using custom colormaps (Blue -> Yellow -> Red). Allow hover interaction to inspect exact temperature values at cursor pixel."
PROMPT #2 — Thermal Analysis 2 
"Create a real-time time-series thermal streaming dashboard using Chart.js. Generate simulated sensor feeds every second. Calculate moving average and highlight anomalous spikes above 65°C in bright red with alarm indicator badges. Maintain high performance without memory leaks."
PROMPT #3 — Weather App 
"Build a minimalist weather widget tailored for Pusan National University campus (Busan latitude 35.23, longitude 129.08). Fetch real weather metrics from OpenMeteo API, calculate thermal comfort index using temperature & humidity, and present it with dynamic styling and dark mode."
